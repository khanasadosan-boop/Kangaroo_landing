# Лендинг «КЕНГУРУ–2027»

Международный конкурс по логической математике «Кенгуру» в Узбекистане. Организатор — ООО «Олимпия».

Статический сайт (HTML/CSS/JS без сборки) и маленький Node-сервер без зависимостей для Railway.
Мобильная версия — основная, десктоп адаптивный. Языки: русский и узбекский (латиница с Ö, Ğ, Ş, Ç).

## Запуск локально

```bash
npm start          # http://localhost:3000
```

Узбекская версия: `/?lang=uz` или короткая ссылка `/uz`. Выбранный язык запоминается в браузере.

## Деплой на Railway

1. Railway → New Project → Deploy from GitHub repo → выбрать этот репозиторий.
2. Railway сам определит Node.js и запустит `npm start` (настройки — в `railway.json`, healthcheck `/healthz`).
3. Settings → Networking → Generate Domain (или подключить свой домен).

Переменные окружения не нужны: порт берётся из `PORT`, который задаёт Railway.

## Что и где менять

Почти всё настраивается в **`public/config.js`**, вёрстку трогать не нужно:

| Что | Где в `config.js` |
|---|---|
| Ссылка на сайт регистрации, Telegram-бот, канал, телефон | `links` |
| Ссылки на положение, оферту, политику конфиденциальности | `links.rules`, `links.offer`, `links.privacy` |
| Цены и даты повышения | `prices` — актуальная цена, зачёркивание прошедших тарифов, сумма экономии и таймер считаются автоматически (время ташкентское) |
| Дата конкурса | `contestDate` (пока `null` — «после утверждения») |
| Статистика (1991, 110+, 7 млн+) | `stats` |
| Страны на карте | `map.countries` (коды ISO alpha-3) |
| Фотографии | `images` (файлы лежат в `public/assets/img/`) |
| Задача «Кенгуру» | `task` (варианты, правильный ответ, рисунок); тексты вопроса и решения — в `public/i18n.js` |
| Счётчики аналитики | `analytics.ga4`, `analytics.yandexMetrika`, `analytics.metaPixel` |

Все тексты обеих языковых версий лежат в **`public/i18n.js`**.

### Аналитика

Когда ID заполнены, счётчики подключаются сами. Все события также попадают в `window.dataLayer` (для GTM):

- `click_register_site`: клик «Зарегистрироваться» (параметр `placement`: header, hero, price, task, final, sticky)
- `click_register_telegram`: клик «Через Telegram» (тот же `placement`)
- `task_answer`, `task_show_solution`, `faq_open`, `lang_switch`

В Метрике это цели типа «JavaScript-событие» с теми же именами.

### Рекламный трафик (Telegram / Instagram)

Метки `utm_*` из адреса страницы передаются на сайт регистрации, вместе с `utm_content` = место кнопки.
В Telegram-бот передаётся `?start=landing_<utm_source>_<utm_campaign>`, так что в боте видно, откуда пришёл пользователь.
Пример ссылки для рекламы: `https://<домен>/?lang=uz&utm_source=instagram&utm_campaign=nov`.
